# 该还不还 Should-I-Prepay

人生现金流与提前还款决策分析器。模拟从买房到退休的完整现金流——收入、支出、房贷、车贷、公积金、理财——通过多方案并排对比，直接回答那个纠结多年的问题：

> **我到底该不该提前还房贷？还了得到什么、损失什么？资金链安全吗？**

## 为什么需要它

市面上几乎所有房贷计算器都只做一件事：算"提前还能少付多少利息"。但真实的决策远比这复杂：

| 常见误区 | 该还不还的做法 |
|---|---|
| 少付利息 = 赚到 | 提前还款占用的钱放弃了理财收益。同时展示「名义少付利息」和扣掉机会成本后的「**真实节省**」两个口径 |
| 只看贷款本身 | 把**人的一生**放进模型：收入的涨跌与断崖、通胀下的生活支出、买车装修教育等大额事件 |
| 公积金余额躺着不算 | 公积金不能自由取现、机会成本≈0，应该**优先烧它**；支持月冲、一次性冲抵、退休取出三种策略 |
| 理财按理想收益算 | 内置**压力测试**：按「预期收益 − 最大亏损」重跑一遍，看悲观情形下会不会断粮 |
| 给出数字不给结论 | 输出直白的决策结论卡 + **宽心指数**（0–100 流动性安全分）+ 盈亏平衡临界收益率 |

## 功能一览

- **输入**：贷款（商贷/公积金贷/车贷，含未来利率预期）、年收入时间线（年终奖、收入断崖）、固定与生活支出（通胀递增）、活钱与多个理财池（定投计划）、公积金账户、人生大事（首付/购车/卖房…）
- **方案对比**：2–4 个提前还款方案并排模拟，区间式还款编排（第几年到第几年、每年/每半年还多少）
- **输出**：净资产演化、流动资产、活钱余额（含应急底线）、贷款余额四张核心图 + 双口径节省对比 + 宽心指数卡 + 分级预警面板 + 盈亏平衡图
- **时间轴**：自动推导关键节点——活钱见底、开始花理财、资金断裂、贷款还清、退休、收入断崖

## 快速开始

```bash
pnpm install
pnpm dev      # 开发服务器
pnpm test     # 引擎单测 + 页面冒烟测试
pnpm build    # 生产构建（纯静态产物，可部署到任意静态托管）
```

## 隐私

**零服务端**。所有计算在浏览器内完成，所有数据只存在本机 localStorage，支持 JSON 导出备份。没有任何上传、统计或遥测。
